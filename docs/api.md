# Overheard API (v1)

Hono on Cloudflare Workers, served at `api.overheardbirds.app/v1`.

The OpenAPI spec is generated from zod schemas (`@hono/zod-openapi`). Interactive docs are at `/docs`: dev only, or admin-gated in prod. The iOS client is generated from the spec with `swift-openapi-generator`.

## Conventions

- Walk and detection IDs are generated by the phone, so a retried upload doesn't create a duplicate.
- List endpoints use cursor pagination (`?cursor=`).
- Images are uploaded through the Worker, which stores them in R2; D1 stores only R2 keys.
- Shared locations follow the privacy rules in `todo.md`: a ~500 m grid, route ends trimmed, and no location for sensitive species.

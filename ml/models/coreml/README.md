# Built model files

These are generated by the scripts in `ml/` and bundled by the iOS app. They're stored here, with the `.mlpackage` folders in Git LFS, so the app builds without the TensorFlow conversion pipeline.

| File | From | What it is |
|---|---|---|
| `BirdNETAudio.mlpackage` | `convert.py` | BirdNET v2.4 audio classifier: 3 s of 48 kHz mono audio → 6,522 logits |
| `BirdNETMeta.mlpackage` | `convert.py` | BirdNET v2.4 location model: [latitude, longitude, week] → per-species occurrence |
| `labels.txt` | `convert.py` | BirdNET's `Scientific_Common` labels, where line index = output index |
| `species.json` | `bird_labels.py` | Stable species codes (eBird) and names for each output index, with a bird/non-bird flag |

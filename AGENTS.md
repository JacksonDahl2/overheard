## What this is

**Overheard: Bird Journal** is an iPhone app that listens during walks and identifies birds by sound **on the device**, using BirdNET through Core ML. It draws each walk as a hand-drawn field-journal page, and friends follow each other's walks.
- Free, for friends and family. No monetization.
- Distributed through TestFlight first.
- Domain: `overheardbirds.app`.

## Stack

- **iOS** (`apps/ios`): SwiftUI and SwiftData, iOS 17+, Swift 5 language mode.
  - BirdNET v2.4 runs through Core ML. The project is generated by XcodeGen from `project.yml`.
  - Detection code lives in the local Swift package `apps/ios/OverheardKit` (iOS + macOS), shared by the app and the Mac eval tool. Put pipeline logic there, not in the app target.
- **ML** (`ml/`): Python 3.11 venv with TensorFlow 2.15 and coremltools 9.
  - It converts BirdNET and precomputes the location filter tables.
- **Backend** (planned): TypeScript on Cloudflare Workers.
  - **Hono** for the API and **Drizzle** for D1.
  - R2 for images and Queues for art jobs. Terraform for infrastructure. pnpm workspaces, no Turborepo.
- **Auth** (planned): Sign in with Apple only.
- **Observability** (planned): traces go to Honeycomb (OTLP from Workers), and all errors go to Sentry.
- **Bird art:** `gemini-3-pro-image` through the Batch API, drawn on flat white, then cut out to a transparent PNG.

## Quick start

```sh
# Node (for art scripts now, backend later)
nvm use                                  # Node 24 from .nvmrc

# BirdNET model files (gitignored, CC BY-NC-SA). Full steps in ml/README.md
cd ml
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -r requirements.txt
# download + unzip BirdNET_v2.4_protobuf.zip into ml/models/birdnet-v2.4/protobuf (see ml/README.md)
.venv/bin/python -I convert.py           # → models/coreml/BirdNETAudio.mlpackage, labels.txt
.venv/bin/python -I species_list.py      # → models/coreml/species-central-park.json
.venv/bin/python -I verify.py            # Core ML vs TensorFlow check

# iOS
cd ../apps/ios
xcodegen                                 # regenerate after editing project.yml
open Overheard.xcodeproj                 # ⌘R onto a connected iPhone

# Detection eval (same Swift pipeline as the app, runs on the Mac)
ml/.venv/bin/python -I ml/eval/fetch.py  # data; birds need XENO_CANTO_API_KEY in .env
swift run -c release --package-path apps/ios/OverheardKit overheard-eval --verbose   # ~75 s; --no-mix skips city-noise runs
swift test --package-path apps/ios/OverheardKit

# Compile check without signing (CI or agents)
xcodebuild -project Overheard.xcodeproj -scheme Overheard \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build

# Image model trial (needs GEMINI_API_KEY / OPENAI_API_KEY in .env)
node --env-file=.env art/model-comparison/run.mjs
```

## Conventions

- **Secrets:** keep them in `.env` (gitignored). Never commit keys, and never print them in logs or output.
- **Licensed files:** BirdNET model files are CC BY-NC-SA and gitignored. Don't commit them.
- **Xcode project:** don't edit or commit `Overheard.xcodeproj`. Change `apps/ios/project.yml` and run `xcodegen`.
- **Python:** run it with `.venv/bin/python -I`. Python on this machine resolves through pyenv and conda, so use the venv. `.vscode/settings.json` points the editor and Pylint at `ml/.venv`.
- **UI:** tokens and fonts come from `docs/design.md`. No emoji, and touch targets are at least 44 pt.
- **Bird size:** on Listen and Journal pages, a bird's size means call count and nothing else. Rarity is shown with the red-ink "naturalist flourish".
- **Location privacy:** blur shared points to a ~500 m grid, trim ~200 m from the start and end of routes, and show no location for sensitive species.
- **IDs:** the phone generates walk and detection IDs, which makes uploads safe to retry.
- **Commits:** small and descriptive. Update `todo.md`, `docs/decisions.md` and this file in the same commit when they change.

## Gotchas

- **BirdNET audio model:** input `inputs` is [1, 144000] Float32 (3 s at 48 kHz mono). Output `Identity` is [1, 6522] logits. Confidence is `sigmoid(clip(x, -15, 15))`.
- **Labels:** `labels.txt` lines look like `Scientific name_Common name`. Its line index equals the output index.
- **BirdNET weeks** run 1–48, four per month: `week = (month-1)*4 + min(4, (day-1)/7 + 1)`.
- **Location (meta) model:** it doesn't convert to Core ML (coremltools fails on `ExpandDims` of a scalar). Precomputed per-week tables stand in for it, Central Park only for now.
- **Filter threshold:** 0.03 drops some late migrants (e.g. Black-throated Blue Warbler in mid-October). Tuning it is a TODO.
- **Audio session:** use `.record` with `.measurement` mode. Other modes apply voice processing that suppresses birdsong.
- **Free signing:** builds expire after 7 days. The Personal Team ID is set in `project.yml`. The first install needs Settings → General → VPN & Device Management → Verify App; if that fails, try cellular instead of Wi-Fi.
- **Gemini images:** they come back as JPEG, even when saved as `.png`.
- **Shell noise:** the user's shell prints `_encode`/`_decode` noise from gvm on `cd`. It's harmless.
